# 行情数据与口径

首页顺序固定为上证指数、深成指、创业板指、科创综指、科创50、沪深300、中证1000、证券板块、银行板块。成交额单位是亿元（元除以 100,000,000），放量/缩量分别表示相对上一交易日同期增加/减少，百分比以同期金额为分母。基数为 0 时仍可提供差额，百分比为空。

## 数据来源

| 行情 | 代码 | 来源 |
| --- | --- | --- |
| 七个指数（按上文顺序） | `sh000001`, `sz399001`, `sz399006`, `sh000680`, `sh000688`, `sh000300`, `sh000852` | 腾讯财经指数行情统计口径 |
| 沪深成交额 | `sh000002`（A 股指数）、`sz399107`（深证 A 指） | 腾讯财经上海 A 股 + 深圳 A 股，排除 B 股和北交所 |
| 证券板块、银行板块 | `90.BK0473`、`90.BK0475` | 东方财富行业板块（证券Ⅱ、银行Ⅱ） |

腾讯使用[日分时接口](https://web.ifzq.gtimg.cn/appstock/app/day/query?code=sz399001)。实测含五个交易会话，`date` 是 `YYYYMMDD`，每个会话自己的 `prec` 是前收；每行第 4 列是**当日累计成交额（元）**，直接采用。七个指数金额遵循腾讯行情统计，例：实测深成指与同源深证综指的快照成交额一致，和深证 A 指略有差异，不能当作 500 只成分股独立统计。上海、深圳 A 股序列覆盖两个互斥市场，合计只取这两条序列的同日期同分钟；九项指数和板块相互重叠，不参与汇总。

东方财富采用[板块页面脚本](https://quote.eastmoney.com/newstatic/build/bk2.js)及[官方图表脚本](https://emcharts.eastmoney.com/ec/3.18.1/emcharts.min.js)使用的 `https://push2.eastmoney.com/api/qt/stock/trends2/get`，请求最近两日。其分钟列表第 3 列是点位，第 7 列是**单分钟成交额（元）**，按交易日分别累加。使用数据中最新会话的前收计算涨跌幅，前收缺失时涨跌幅为空。对[证券Ⅱ](https://quote.eastmoney.com/bk/90.BK0473.html)、[银行Ⅱ](https://quote.eastmoney.com/bk/90.BK0475.html)的实际接口请求均在收到 HTTP 响应前断开（`RemoteProtocolError`），尚无可用的东方财富原始分时样本；适配器按官方脚本字段和受控响应验证。两项失败时独立显示不可用或带日期的上次成功缓存。

这些公开接口未核实有版本或可用性承诺。Worker 只请求上述固定 HTTPS 端点、禁止重定向，每次网络尝试最多 4 秒（含 DNS），响应上限 256 KiB，传输失败最多重试一次。进程最多并行执行两个阻塞 DNS 查询，查询占满时请求快速失败。证券代码、名称、日期、分钟和数值均校验后才进入缓存。

## 时间与缓存

- 盘中取已返回的最新有效交易分钟，只与上一交易会话的同一时刻比较。周一通常比较周五；前日来自数据源的会话序列。基准日期为空或分钟窗口不完整时不计算差额。
- 09:30–11:30、13:01–15:00 是有效分钟；13:00 可出现在源数据中作为午后起始标记，午休和该标记不产生新的交易额。收盘后只比较完整交易日。若属于单分钟增量源且当日有缺行，累计额也不可用。
- 周末展示最近交易日。工作日开盘后没有当日行情时标明可能休市或数据源延迟；没有独立节假日历。获取时间和交易时间是两回事：拉取较迟、数据没有到达预期分钟或最新更新失败时，界面会标为已过期。
- Worker 首次启动立即尝试更新，盘中约每 60 秒，休市约每 15 分钟，接近开盘时缩短等待。SQLite 租约避免多个 Worker 同时轮询；网络调用期间不占用数据库事务。失败保留各项最近成功快照，沪深合计不会混用两个不同日期或分钟的来源。

## 接口与升级

`GET /api/market` 是无需登录的只读缓存接口。顶层 `source`、`source_url`（腾讯日分时入口）、`fetched_at`（最后成功获取的 Unix 秒或 null）、`stale`、`status`（`ready` / `partial` / `unavailable`）、`message` 描述快照状态。返回固定顺序的 `items` 和一项 `total`。

每项以 `key`、`name`、`code` 标识；`price`、`change_pct` 是点位和涨跌幅，`amount_yi`、`delta_yi`、`delta_pct` 是成交额、差额和百分比；未取得的数值为 null。`trade_date`、`as_of`、`previous_date` 分别为交易日、北京时间截止分钟、基准日期。`points` 为当日分时 [{time, price}]；合计只有成交额相关字段，走势图为空。`source`、`scope` 标注来源和范围；`status`、`message`、`fetched_at`、`stale` 描述该项是否可用及缓存状态。

Web 和 Worker 必须挂载同一 SQLite 卷，行情仅在 Worker 运行时更新。升级前按 [README 的备份步骤](../README.md#运维备份和升级)备份，随后执行 `docker compose up -d --build --wait`；若使用 DTK 共享网络，则执行 `docker compose -f compose.yaml -f deploy/notify.collector.yaml up -d --build --wait`。行情表在应用启动时创建，保留原记录、配置和密钥，部署没有额外环境变量。

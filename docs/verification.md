## 验证边界

外部适配器测试使用受控响应，不等同真实抖音采集。尚未提供真实 Cookie、模型 API Key 和 SMTP 凭据，因此真实抖音 → 语音识别 → AI → 邮件的完整外部链路未验证。本地 faster-whisper 模型未在 Windows 环境实际下载识别。

Docker 验收使用独立临时密码、127.0.0.1:18765 端口和独立数据卷，没有配置真实博主或向外发送邮件。验收结束后清理临时容器和数据卷；保留构建好的本地镜像供部署使用。DTK 上游容器栈及其真实登录身份未在本次运行验收中启动。

# 长虹财经关注与行情侧栏

用户已要求将网站用于财经博主追踪，并确认成交额以亿元表示、与上一交易日同期比较。沿用现有 FastAPI、Jinja、SQLite、独立 worker 和 Docker 部署；当前预览服务保持停止。

## 品牌与布局

网站名称统一为“长虹”，包含前后台标题、品牌标记、README 和邮件署名。正文用中性黑白灰，链接、按钮、强调文字及上涨色使用低饱和枣红；下跌使用中性灰与负号，所有明暗模式均无绿色。首页定位文案改为财经博主的视频更新。

桌面在记录右侧增加约 20rem 行情栏，主记录宽度保持可读；窄屏行情位于记录上方，可折叠九项详细行情，合计保持可见。保留原记录六字段顺序、时间倒序和主题持久化，前台无后台登录按钮。

## 行情与比较口径

九项按用户顺序固定显示：上证指数、深成指、创业板指、科创综指、科创50、沪深300、中证1000、证券板块、银行板块。各项展示最新点位、涨跌幅、当日分时折线、累计成交额、较上一交易日同期放量/缩量数额与百分比。零差值显示持平；缺失数据显示“暂无可比数据”，不能填 0。

盘中对齐上一交易日的同一交易分钟，午休沿用 11:30，收盘比较完整交易日。前日是数据源连续交易会话中的上一日，不能简单减一个自然日；数据截断、缺行或只有一天时拒绝产生误导性比较。每项标明行情日期、截至分钟、基准日期；周末展示最近交易日，不伪装当日实时。

总额独立于九项卡片。必须采用有明确全市场覆盖的沪深成交额序列，排除北交所，不将重叠指数或板块相加，也不能把成分股成交额当作全市场。界面明确数据源及具体覆盖口径，无法取得可靠合计时显示不可用而非估算。

## 数据流与容错

行情供应商适配器返回标准分钟数据，计算层负责累计金额与严格同期比较，存储层保存成功结果和拉取状态；浏览器仅访问本站 `/api/market`，不直连行情供应商。

默认指数源采用腾讯财经 `web.ifzq.gtimg.cn/appstock/app/day/query`，七项分别为 sh000001、sz399001、sz399006、sh000680、sh000688、sh000300、sh000852。实测均返回最近五个交易日的带日期分时序列，行内金额为累计元金额，不可再次求和；每个日期自身 `prec` 为其前收盘。总额单独读取 sh000002 与 sz399107 的沪深 A 股行情序列并在相同日期、分钟对齐后相加（不包含北交所和 B 股），明确为腾讯行情统计口径，不能用其余九项求和。证券/银行使用东方财富 BK0473/BK0475 分时，源码参考 AKShare；两家源均保留适配器替换边界。

外部请求有超时、大小上限、固定来源地址和有限重试；不引入 pandas/AKShare 大依赖。行情 worker 独立线程，约每 60 秒刷新，非交易时段降低频率。多 worker 使用租约防重复拉取，异常不阻塞原视频和邮件任务。腾讯序列包含 13:00 的午后起始标记（累计额与11:30相同），它不是新增成交额。东方财富分钟额需要累计，与腾讯分开解析。

接口只读取数据库缓存，不在用户请求内拉取外网。成功数据保留，失败只更新状态；前台标明缓存、过期、休市和数据时间。无 worker 或首次启动无数据时九项占位清楚显示等待更新。浏览器定时刷新，隐藏页面暂停；保留最后成功画面并显示网络失败。

## API 契约

`GET /api/market` 返回 `{source, source_url, fetched_at, stale, status, message, items, total}`。`fetched_at` 是 Unix 秒或 null；status 是 `ready`、`partial` 或 `unavailable`。

`items` 按九项固定顺序返回对象；`total` 为同形对象，name 为“沪深成交额”，无 price/百分比走势图也可。对象字段：`key,name,code,price,change_pct,amount_yi,delta_yi,delta_pct,trade_date,as_of,previous_date,points,status,message,source,scope,fetched_at,stale`。数值缺失为 null；`points` 为 `{time:'09:30',price:123.45}` 数组；对象 status 为 `ready` 或 `unavailable`。`as_of` 为北京时间 HH:MM。total.scope 必须注明覆盖，元转亿元仅在计算输出时除以 100000000。

## 验收

用确定的双交易日分钟样本验证放量、缩量、持平、零基数、午休、收盘、周末、缺失分钟、上一日数据缺失及不同步市场合计。HTTP 验证无认证公开行情、无外网请求、旧数据保留、原后台安全和原记录字段顺序不回归。浏览器验证桌面、390px 手机、明暗模式和失败状态。真实公开源低频联调，记录可用性限制，不把模拟数据当真实行情。
